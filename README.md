# BLOOMORA 🌷

A handmade boutique website.

Instagram: @bloom.ora26

## Files

- index.html
- style.css
- script.js
- assets/

## How to add products

1. Add your product image to assets.
2. Open script.js.
3. Add a new product object.
4. Enter its name, description and image path.
5. Save the file.

## How to change the banner

Replace:

assets/bloomora-banner.jpg

with your new banner image.

Keep the same filename.

## How to publish

1. Create a GitHub account.
2. Create a public repository called bloomora.
3. Upload all files and the assets folder.
4. Open Settings.
5. Open Pages.
6. Select Deploy from a branch.
7. Select main and /(root).
8. Click Save.

Your website will be published!
